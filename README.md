# PUYA_orgel_anpanDRIVE

🧸 PY32F002Aマイコンを搭載した「キッズドライバーのハンドル」向け電子オルゴールプロジェクトです。
おもちゃの修理やカスタマイズ、電子工作のベースとしてご活用ください。

---

## 📌 プロジェクト概要

本プロジェクトは、安価な **PY32F002Aマイコン** を使用して、キッズドライバー（ハンドル玩具）に組み込む電子オルゴールを製作・修理するためのリソースを公開しています。

- **搭載マイコン:** PUYA社製 PY32F002A
- **目的:** おもちゃの修理（Toy Repair）、音楽再生機能の追加

---

## 📂 リポジトリの構成

本リポジトリには以下のデータが含まれています。

| フォルダ・ファイル名 | 内容 |
| :--- | :--- |
| `Circuit_Schematic/` | 電子回路図データ |
| `PCB_Layout/` | 基板レイアウト（プリント基板データ） |
| `orgel1_4_anpanDRIVE_HANDLE/` | マイコン用のソースコード / ファームウェア |
| `image/` | プロジェクトに関する画像・写真素材 |
